# Лабораторные работы №2, №3 и №4 по информатике

Проект объединяет три лабораторные работы, посвящённые разработке абстрактных типов данных, алгоритмов обработки последовательностей и ленивых вычислений.

## Лабораторная работа №2

Реализована библиотека полиморфных последовательностей с изменяемыми и неизменяемыми реализациями на основе динамического массива и связного списка.

Основные возможности:

* `DynamicArray` и `LinkedList`;
* интерфейс `Sequence`;
* `Mutable` и `Immutable` реализации;
* `BitSequence`;
* алгоритмы `map`, `where`, `reduce`, `zip`, `split`, `slice`, `skip`;
* перегрузка операторов;
* `Option<T>` для безопасной обработки ошибок;
* консольный интерфейс и модульные тесты.

## Лабораторная работа №3

Реализован абстрактный тип данных **кусочной функции**.

Основные возможности:

* изменяемая и неизменяемая реализации;
* добавление и изменение сегментов;
* вычисление значения функции;
* проверка непрерывности и монотонности;
* обход сегментов;
* алгоритмы `map`, `where`, `reduce`;
* перегрузка операторов и модульные тесты.

## Лабораторная работа №4

Реализована библиотека ленивых последовательностей и потоковой обработки данных.

Основные возможности:

* `LazySequence`;
* индексация и длины с использованием ординальных чисел;
* операции `append`, `prepend`, `insert`, `concat`, `map`, `where`, `reduce`, `zip`, `take`, `interleave`;
* генераторы конечных и бесконечных последовательностей;
* кольцевое окно генерации;
* потоки чтения и записи;
* онлайн-статистика потока;
* консольный интерфейс, демонстрационные сценарии и модульные тесты.
