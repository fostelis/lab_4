### Основная идея ЛР-4

`LazySequence<T>` не хранит всю последовательность. Она хранит правило получения элемента. Каждая операция создаёт новое правило поверх предыдущего правила.

Например, цепочка:

```text
sequence.append(x).insert_at(y, i).map(f)
```

создаёт несколько связанных правил, а не новый материализованный массив.

### Ординальные числа

Файл `ordinal_number.h` содержит универсальную абстракцию числа вида:

```text
omega * k + n
```

Этот класс не знает, является ли число индексом, длиной или позицией. Логика использования вынесена в `ordinal_operations.h`.


### Конкатенация бесконечных последовательностей

Если сконкатенировать две бесконечные последовательности, получится длина `omega*2`.

```text
omega*0+i  элемент первой последовательности
omega*1+j  элемент второй последовательности
```

Если сконкатенировать четыре бесконечные последовательности, получится длина `omega*4`.

### Кольцевое окно

Для рекуррентной генерации используется `generation_window<T>`. Память выделяется под фиксированную ёмкость окна. Если ёмкость равна 20, то в памяти хранится максимум 20 последних сгенерированных элементов.

Когда добавляется новый элемент и окно заполнено, он записывается поверх самого старого элемента. Пересоздания окна и копирования всего окна нет.

Если запрашиваемый элемент находится внутри окна, он возвращается сразу. Если элемент впереди, генератор досчитывает значения и двигает окно. Если элемент слишком далеко позади окна, выбрасывается исключение.

### Генераторные правила

Основной интерфейс находится в `element_generation_rule.h`.

Правила:

- `materialized_sequence_rule.h` — готовая конечная последовательность;
- `recurrent_sequence_rule.h` — рекуррентная или бесконечная последовательность;
- `sequence_transformation_rules.h` — `append`, `prepend`, `insert`, `concat`, `map`;
- `interleaved_sequence_rule.h` — round-robin объединение;
- `lazy_sequence.h` — публичный фасад;
- `lazy_sequence_generator.h` — последовательный генератор.

### Потоки и статистика

- `streams.h` — потоки чтения и записи;
- `online_statistics.h` — онлайн-статистика;
- `lab4_format.h` — вывод объектов ЛР-4.

Статистика считает `count`, `min`, `max`, `mean`, `median`. Медиана поддерживается двумя кучами.
